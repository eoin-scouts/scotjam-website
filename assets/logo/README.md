# Header logo

The purple header is the Scouts logo with the word **ScotJam** beside it.

The file `placeholder.svg` is an empty slot.  It is **not** the Scouts logo.  Do not draw a fleur-de-lis yourself, and do not trace one from a screenshot.

## What to drop in

1. Download the official **white** Scouts Scotland logo from the Scouts brand centre: [scouts.org.uk/brand](https://www.scouts.org.uk/brand) or [scoutsbrand.org.uk](https://scoutsbrand.org.uk).
2. Save it in this folder, for example `scouts-scotland-logo-white.svg` (or `.png`).
3. On every page, change the header image so `src` points at that file.  Search the site for `assets/logo/placeholder.svg`.
4. Leave the word ScotJam in the HTML, next to the image.  It is the local name, set in Nunito Sans Extra Bold.  Do not typeset that word inside the logo file, and do not add shadows, outlines or extra words to the artwork.
5. Keep some clear space around the logo, as the brand guidelines show.  Do not stretch it.

Use the **white** logo.  This header is Scouts Purple, and the guidelines say the logo on purple is white.  On a white background the Scouts Scotland logotype would be Scouts Blue (`#006ddf`).  Do not recolour the logo in teal, yellow, orange or other palette colours.

Do not reuse the “ScotJam 2026 Logo” file.  The header for this site is the Scouts logo plus the word ScotJam.

The browser icon (`assets/favicon.svg`) is a plain purple square, not the Scouts logo.  You can leave it, or replace it later with artwork the brand centre allows for a small icon.

Suggested `alt` text: leave `alt=""` on the logo image while the word ScotJam sits beside it, so screen readers do not say the name twice.  The link already says “ScotJam home”.
